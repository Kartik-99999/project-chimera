chimeraWorkbench launcher

The Workbench needs its app server

You reached the Workbench folder through the static site server, which cannot run the application. Start the app server from the repository root:

.venv/bin/python -m workbench.server --port 8783
Open Workbench Checking app server…

If the button does not open the app, the server above is not running yet — start it first, then retry.
