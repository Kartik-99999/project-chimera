Empirical discipline · provisional evidence

Where every result comes from.

Chimera is held to one evidentiary rule: execution is never conflated with verification. Every record is separated across two splits × two drivers — held-out and development, Chimera and replay baseline — run through identical cells. Held-out figures stay explicitly provisional until the full human audit lands.

MethodProvenanceAuditsLimitsReports

Methodology

Designed before it was run.

Experiment design: manifests pin 36 cells per held-out run, 5 measured trials per cell (+1 warm-up), deterministic run-derived seeds. Postconditions P1–P3 are evaluated by verify_postconditions from an independent snapshot — never from the agent's trace.

Reproducibility

experiments/matched-budget-v1/run_experiment.py + analyze.py re-run and re-analyze the follow-up; tools/mini_review.py (validate, apply-verdicts dry-run by default) replays human review. Seed 20261030, identical cells across both drivers, no telemetry backend.

Defined scope · honest capability boundaries

What Chimera cannot do yet.

Chimera is not a general-purpose autonomous agent for arbitrary websites. Each boundary below is explicit — what holds inside it is measured, and what lies outside it is not claimed.

Scope

One measured workflow

The 520-episode benchmark covers a single create-a-project flow against a local demo page. Nothing measured transfers to other sites, workflows, or real web complexity.

How it works
Boundary

No AI model

The agent is a deterministic script. There is no model adapter, no Baseline B, and no cost, robustness, or adversarial comparison.

Research Console
Scope

Two fault knobs

Only slowness and disabled inputs are tested; the held-out split varies values (800–3900 ms), not fault types.

See the matrix
Boundary

No recovery layer

Bounded retry plus honest failure reports. No reset-and-retry, no replanning, no recovery rate to quote.
