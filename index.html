What Chimera does

One small task, performed the same way every time.

Chimera's referee is fixed scripts, not an AI model: no learning, no randomness, and network calls only to each workflow's approved target site — while Meta's Muse Spark acts as the browser agent it judges. It runs seventeen fixed workflows — demo flows, store checkouts, site lookups — and the measured 520-episode evaluation covers the create-a-project flow against four fault conditions: normal, slow, disabled, and slow + disabled. Design dossier — evidence, system, limits

Current hero art direction

The Computational Weave

A two-dimensional generative line composition: five coloured filament systems approach a shared proof core. The artwork stays intentionally open, with a clear centre and wide white margins. Stage names, metrics, and explanations remain live HTML rather than being baked into the image.

01 / FormWoven geometry

Fine, controlled arcs form five distinct lobes without filling the whole canvas.

02 / ColourContinuous spectrum

Cyan, indigo, rose, orange, and gold mark the progression across the artwork.

03 / InteractionStage-linked focus

Selecting a stage highlights its node; the optional sequence advances gently.

Chimera / Capability boundaries

What is not claimed

  • One measured workflow — the 520-episode benchmark covers a single create-a-project flow on a local demo page.
  • No AI model — the agent is a deterministic script; no model adapter or Baseline B.
  • Two fault knobs — slowness and disabled inputs only; held-out varies values, not fault types.
  • No recovery layer — bounded retry plus honest failure reports.
  • Provisional evaluation — held-out figures await the full human audit (144 sampled, 0 verdicts).
  • Same-machine timings — latencies compare only within this machine.

Chimera / Reproducibility

Re-run it yourself

  • Seed 20261030 — deterministic runs; identical cells across both drivers.
  • Frozen records — figures come from static JSON under artifacts/ plus benchmarks/manifests/; there is no telemetry backend.
  • Serve locally — python3 -m http.server from the repository root, then open the landing.
  • Verify — .venv/bin/python -m pytest tests/test_main_site.py recomputes every displayed figure independently.
