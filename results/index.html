How to read this table honestly
  • Each cell pools several input variants — the per-cell n=5 behind each variant has very wide uncertainty (0/5 → up to 43.4%).
  • Pooled rates mix easy and impossible conditions; compare within a row, not across the whole table.
  • The development split tuned the agent; only the held-out split tests it — and held-out figures are provisional until a full human audit.

Recovery behaviour: retries a little, then gives up honestly

There is no recovery engine: no reset-and-retry, no replanning, no second strategy. The honest achievement here is terminal correctness — every impossible trial was reported as failed, never misreported as success.

How long episodes take

Every dot is one real episode duration. Chimera's failures take seconds because it waits and retries before concluding the task is impossible — replay fails in milliseconds because it never waits.
